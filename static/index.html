🔑 API Key ElevenLabs Khuyên dùng

Cách dễ nhất để tạo giọng nói. Đăng ký miễn phí tại elevenlabs.io → lấy API key từ Profile → API Key.

Chưa đặt API key
📖 Hướng dẫn nhanh
  1. Vào elevenlabs.io → Đăng ký miễn phí
  2. Nhấn avatar góc trái dưới → Profile + API key
  3. Sao chép API key (bắt đầu bằng sk_...)
  4. Dán vào ô bên trái → nhấn Lưu Key
  5. Chọn giọng → nhập text → Tạo Giọng Nói!

🔑 Đăng nhập Minimax Web (Camoufox — Không cần API Key)

Tự động mở trang web Minimax (minimax.io) để lấy Token nội bộ.
Nhấn "Bắt đầu" → Camoufox mở → chỉ cần đăng nhập, phần mềm đọc token ngay (không phải tạo audio nữa). Token này dùng cho cả TTS lẫn tạo voice clone.

"Mở trình duyệt MiniMax" mở thẳng trang Voice Cloning bằng phiên đã lưu và giữ cửa sổ ở lại. Mọi thao tác của bạn trên đó được ghi lại để app học đúng cách gọi API. Bấm "Dừng" khi xong.
